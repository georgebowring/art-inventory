## Important Notes

### Image Migration
The artwork_images and documents tables contain Airtable CDN URLs in the `url` and `original_url` columns.
These URLs are temporary and will expire. You need to:
1. Download each image from the Airtable URL
2. Upload to Supabase Storage (artwork-images bucket)
3. Update the `storage_path` and `url` columns with the new Supabase paths

A separate image migration script can handle this when you're ready for production.

### Vendu Table Overlap
Some records may exist in both Stock and Vendu tables.
The migration deduplicates by Airtable record ID, but since the tables have different IDs,
you may have duplicates that need manual cleanup (same artwork, different record IDs).

### Currency Notes
- All profit/P&L values are stored in USD (matching your Airtable convention)
- Purchase prices are in the original currency as specified per record
- The Airtable Currency/Currency Expenses fields had data corruption (dollar amounts in select fields)
  — these have been cleaned during migration
